TLOU Infinite Ammo v1.0.0 - The Last of Us Part I (PC)

Infinite ammo with normal reloads, for every gun, without finishing the game.
Magazines still empty and you reload as usual; every reload is a full
magazine, and the HUD shows the infinity sign.
F7 = toggle infinite ammo.  F8 = toggle No Reload (player only, off by default).
Settings: TLOUInfiniteAmmo.ini

INSTALL WITH FLUFFY MOD MANAGER
  Put this zip in  Fluffy Mod Manager\Games\TLOU\Mods\  and tick
  "TLOU Infinite Ammo" in Fluffy. Untick it to uninstall.

INSTALL MANUALLY
  Copy version.dll and TLOUInfiniteAmmo.ini into the game folder
  (the folder with tlou-i.exe), e.g.
  C:\Program Files (x86)\Steam\steamapps\common\The Last of Us Part I\
  modinfo.ini and screenshot.png are only for Fluffy.

UNINSTALL MANUALLY
  Delete version.dll, TLOUInfiniteAmmo.ini and TLOUInfiniteAmmo.log
  from the game folder.

CHECK IT WORKS
  After starting the game, TLOUInfiniteAmmo.log in the game folder should
  end with "active: InfiniteAmmo=1". In-game the reserve ammo shows the
  infinity sign.

Tested: Steam, game version 1.1.4.0. If the game updates and the mod's code
patterns are no longer found, the mod writes the reason to the log and does
nothing.
